# Thermodynamic parameter data

`rnastructure-6.6/` contains the 34 unmodified `data_tables/rna.*` free-energy and enthalpy tables distributed with RNAstructure 6.6. Ribon independently parses and validates these text files at build time, then compiles the Turner 2004 nearest-neighbor tables into `ribon-core`.
