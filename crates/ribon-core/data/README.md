# Thermodynamic parameter data

`rnastructure-6.6/` contains the 34 unmodified `data_tables/rna.*` and 33 unmodified `data_tables/dna.*` free-energy and enthalpy tables distributed with RNAstructure 6.6. Ribon independently parses and validates these text files at build time, then compiles the standard RNA and DNA parameter families into `ribon-core`.
