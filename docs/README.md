# Technical Documentation

These documents define Ribon's implementation boundaries, scientific models, validation evidence, and source provenance. For installation instructions and the complete Typst API, see the [package manual](../package/docs/documentation.pdf).

- [Architecture](ARCHITECTURE.md) describes the Rust/WASM and Typst boundaries, protocol, complexity, safeguards, and reproducibility controls.
- [Analysis models](MODEL.md) defines the thermodynamic families, constraints, decoders, specialized analyses, pseudoknot state spaces, and layout methods.
- [Validation](VALIDATION.md) records numerical comparisons, exhaustive checks, performance gates, WASM checks, and image-level regression tests.
- [References](REFERENCES.md) explains where literature, web standards, parameter provenance, and artifact hashes are maintained.
